01 / PROJECT OVERVIEW

Task 5 extends Task 4

Starting point

This assignment builds on the Firebase environment-monitoring platform from Task 4. The existing ESP32 sensor readings, Firebase project, authentication, database, and dashboard remain the foundation.

New capability

Add an ESP32-controlled relay and dashboard settings so a bulb can be operated remotely in MANUAL mode or switched automatically from the LDR reading in AUTO mode.

Project summary

Firebase stores the requested mode and bulb state. The ESP32 reads those values, applies manual or threshold-based logic, switches the relay, then writes the actual bulb state, operating mode, and LDR threshold back to Firebase.

02 / ACTUATOR INTEGRATION

Add relay-based appliance control

Connect a single-channel relay module to the ESP32 as the low-voltage control interface for the appliance. In the provided plan, GPIO 26 drives the relay input.

ESP32 GPIO 26Relay INRelay contacts230 V bulb
CONTROL SIDE

ESP32 signal

The ESP32 output changes the relay-module input according to the selected mode and calculated bulb state.

LOAD SIDE

Relay contacts

Properly rated relay contacts switch the appliance circuit; the relay rating must suit the actual load.

Mains safety

230 V mains wiring can cause fatal electric shock or fire. Disconnect power before wiring. Use a correctly rated relay in an insulated enclosure, keep mains wiring isolated from low-voltage electronics, and have the mains side wired or inspected by a qualified person.

05 / SENSOR-DRIVEN CONTROL

AUTO mode with an LDR threshold

When mode is AUTO, the ESP32 compares the LDR reading against the configured threshold. For this project requirement, values above 3000 switch the bulb ON; values at or below 3000 switch it OFF.

LDR> 3000BULB ON
LDR≤ 3000BULB OFF
CONFIGURED THRESHOLDldrThreshold = 3000

The active threshold is stored in Firebase and reported in the current status so the dashboard can show the decision boundary being used.

Read LDRCompare with 3000Set relay stateUpdate Firebase status

MANUAL mode follows the user's dashboard request. AUTO mode ignores the manual request while active and determines the output from the LDR comparison. Calibrate the threshold against readings from the actual sensor and environment.

06 / DEVICE STATUS & HISTORY

11 / ELECTRICAL SAFETY

Relay and mains precautions

230 V mains can cause fatal shock or fire

Disconnect mains power before wiring. Use a relay rated for the load in an insulated enclosure, maintain isolation between mains and low-voltage electronics, and have mains wiring installed or inspected by a qualified person. Do not handle exposed live wiring during testing.

The ESP32 GPIO is a low-voltage control signal only. Do not connect a mains conductor directly to an ESP32 pin.

The resulting bulb state, mode, and threshold are reported to Firebase and added to historical data for analysis.
