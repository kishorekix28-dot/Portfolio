01 / PROJECT OVERVIEW

Firebase-connected sensor monitoring

Objective

Create a Firebase-based IoT backend and integrate an ESP32 to transmit temperature, humidity, and ambient-light readings in real time for monitoring.

System purpose

The ESP32 reads a DHT11 and LDR, sends sensor data to Firebase Realtime Database over Wi-Fi, and an authenticated web dashboard presents current and historical readings.

Project summary

The ESP32 collects environmental readings from the DHT11 and LDR and uploads them through Wi-Fi to Firebase. Firebase Authentication protects dashboard access, while real-time and historical sensor data are visualized through a web interface.

Protect Firebase credentials and access

Use Firebase Authentication to gate dashboard access. Configure Realtime Database rules so only authenticated, authorized users can access data. Do not expose private credentials or leave production database rules open.

Authentication flow

User opens launch pageLogin pageFirebase AuthenticationDashboard on success

When sign-in fails, the application should show a clear error and keep protected dashboard content inaccessible. The dashboard should provide a logout action that ends the authenticated session.

04 / FIREBASE INTEGRATION

Sensor data integration

The ESP32 joins Wi-Fi, initializes the DHT11 and LDR input, then authenticates with Firebase using the configured API key and Realtime Database URL. It periodically reads sensor values, uploads current readings and a timestamp, and writes historical records.

01

Connect to Wi-Fi

Start the station connection and wait for an internet connection before using Firebase.

02

Initialize Firebase

Install the Firebase ESP32 library and configure the API key, Realtime Database URL, and authentication details, then initialize the Firebase client.

03

Read and publish sensors

Read DHT11 temperature/humidity and the LDR ADC value; update the current database state.

04

Upload current sensor values

Write temperature, humidity, LDR reading, and timestamp to the /current node for the dashboard.

05

Append history

Periodically store sensor readings and a timestamp under /history for later review.

Realtime updates

Firebase /currentFirebase Web SDK onValue()Update dashboard elements

A realtime listener such as onValue() observes values under /current. When the ESP32 publishes a new sensor reading, the JavaScript updates the temperature, humidity, and LDR displays without a manual page refresh.
